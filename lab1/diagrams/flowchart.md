# Flowchart: алгоритм принятия решения по кредитной заявке

Блок-схема описывает, как скоринговая система формирует решение на основе
кредитного рейтинга, кредитной истории и долговой нагрузки заявителя.

```mermaid
flowchart TD
    Start([Начало: получены данные заявителя]) --> Input[/Ввод: рейтинг, история, доход, сумма кредита/]
    Input --> CalcLoad[Рассчитать долговую нагрузку:<br/>платёж / доход * 100%]
    CalcLoad --> CheckHistory{Есть просрочки<br/>более 90 дней?}

    CalcLoad --> CheckHistory{Есть просрочки<br/>более 90 дней?}
+   CalcLoad --> CheckAge{Возраст в диапазоне<br/>21-65 лет?}
+
+   CheckAge -- Нет --> Reject
+   CheckAge -- Да --> CheckHistory{Есть просрочки<br/>более 90 дней?}

    CheckHistory -- Да --> Reject[/Решение: отказ/]
    CheckHistory -- Нет --> CheckScore{Рейтинг >= 600?}

    CheckScore -- Нет --> Reject
    CheckScore -- Да --> CheckLoad{Долговая нагрузка<br/>&lt;= 50%?}

    CheckLoad -- Нет --> ReduceSum[Уменьшить одобряемую сумму<br/>до порога нагрузки 50%]
    ReduceSum --> CheckMin{Сумма >= минимальной<br/>суммы кредита?}

    CheckMin -- Нет --> Reject
    CheckMin -- Да --> Approve[/Решение: одобрено<br/>с уменьшенной суммой/]

    CheckLoad -- Да --> ApproveFull[/Решение: одобрено<br/>на запрошенную сумму/]

    Approve --> End([Конец])
    ApproveFull --> End
    Reject --> End
```

## Пояснения к нотации

- `([...])` — начало и конец алгоритма.
- `[/.../]` — ввод и вывод данных.
- `[...]` — вычислительный блок.
- `{...}` — условие (ветвление), подписи на стрелках — результат проверки
