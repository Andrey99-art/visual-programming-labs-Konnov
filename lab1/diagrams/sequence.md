# Sequence Diagram: обработка заявки на кредит

Сценарий: полный путь заявки от подачи до выдачи средств либо отказа.

```mermaid
sequenceDiagram
    actor Client as Клиент
    participant Manager as Кредитный менеджер
    participant Scoring as Скоринговая система
    participant Core as Банковская система

    Client->>Manager: Подать заявку и документы
    Manager->>Manager: Зарегистрировать заявку в системе
    Client->>Manager: Подать заявку и документы
    Manager->>Manager: Зарегистрировать заявку в системе
+   Manager->>Core: Проверить наличие действующих кредитов
+   Core-->>Manager: Список текущих обязательств

    loop Пока пакет документов неполный
        Manager->>Client: Запросить недостающие документы
        Client-->>Manager: Предоставить документы
    end

    par Параллельные проверки
        Manager->>Scoring: Запросить кредитный рейтинг
        Scoring-->>Manager: Рейтинг заявителя
    and
        Manager->>Core: Запросить кредитную историю в БКИ
        Core-->>Manager: Кредитная история
    end

    Manager->>Scoring: Передать данные на формирование решения
    Scoring-->>Manager: Решение по заявке

    alt Решение положительное
        Manager->>Client: Передать кредитный договор на подпись
        Client-->>Manager: Подписанный договор
        Manager->>Core: Открыть счёт и перечислить средства
        Core-->>Manager: Подтверждение перечисления
        Manager->>Client: Уведомить о выдаче кредита
    else Решение отрицательное
        Manager->>Client: Уведомить об отказе
    end
```

## Пояснения

- **loop** — цикл дозапроса документов: повторяется, пока пакет не станет полным.
- **par** — параллельные проверки: скоринг и запрос в БКИ независимы и выполняются одновременно.
- **alt / else** — альтернативные сценарии после решения: выдача кредита либо отказ.
